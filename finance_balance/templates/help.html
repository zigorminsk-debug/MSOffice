Как пользоваться программой

Ниже приведены правила расчёта и готовые примеры заполнения для типовых операций Игоря и Юры.

Основное правилоОперацииЗаймыПоля формыБаза данных
01

Основное правило

Сначала выберите «На чей баланс» относится операция.

+

Увеличить задолженность

Увеличивает долг выбранного собственника перед вторым.

−

Уменьшить задолженность

Уменьшает долг выбранного собственника перед вторым.

Итог: положительное сальдо означает «Юра должен Игорю», отрицательное — «Игорь должен Юре». Все итоги показываются в BYN.

05

Пароль, сеть и база данных

При первом запуске создаётся пароль не короче 6 символов. Он используется для запуска GUI и входа через браузер. Изменить пароль можно кнопкой «База и доступ».

В этом же окне можно открыть balance.db из общей папки, в том числе по пути \\SERVER\Share\balance.db, или создать новую базу. Для нескольких пользователей рекомендуется включить сетевой HTML-доступ: база останется на одном компьютере, а остальные пользователи войдут через браузер по показанному адресу.

Сетевой HTML-доступ: включите соответствующий флажок, сохраните настройки и нажмите «HTML-интерфейс». На другом компьютере откройте адрес вида http://192.168.1.10:8080 и введите пароль приложения.
Важно при обновлении

Заменяйте только Balance-Igor-Yura.exe. Не удаляйте balance.db и balance-config.json. Для резервной копии закройте программу и скопируйте оба файла.

Ошибочную запись можно удалить из журнала. Кнопка «Экспорт CSV» сохраняет таблицу для Excel.
