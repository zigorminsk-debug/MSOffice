# Валютный баланс USD

Одностраничный интерфейс для ручного учёта покупки и продажи USD за белорусские рубли (BYN). По виду экран повторяет вкладку валютного баланса из предоставленного примера.

## Запуск

```bash
python3 -m http.server 8000 --bind 0.0.0.0
```

Откройте `http://localhost:8000`.

## Windows-приложение

Workflow GitHub Actions собирает `FITNES-Currency.exe`. После успешной сборки скачайте артефакт `fitnes-currency-balance-windows-exe` в разделе **Actions → Currency balance artifact → Artifacts**. Приложение открывает экран в отдельном окне WebView; для запуска нужен Microsoft Edge WebView2 Runtime (обычно уже установлен в Windows 10/11).

## Возможности

- вкладка «Валютный баланс USD» с формой «Операция с USD»;
- ввод суммы в BYN или USD для покупки и продажи, с расчётом второй стороны обмена;
- ручной курс BYN/USD: курс продажи банка при покупке долларов и курс покупки банка при продаже;
- списание и зачисление на соответствующие валютные остатки;
- реализованная прибыль или потеря по средневзвешенной себестоимости USD;
- журнал операций, начальный остаток BYN и экспорт CSV;
- сохранение журнала в `localStorage` браузера.

Приложение только ведёт учёт, не подключается к банку и не отправляет платежи. Комиссии банка не учитываются.
