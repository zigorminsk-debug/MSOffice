# Fitnes

**Fitnes** — локальная программа для учёта взаиморасчётов двух собственников. Есть два равноправных интерфейса:

- **GUI** — настольное окно для Windows/Linux;
- **HTML** — адаптивная страница, открывающаяся в браузере.

Оба интерфейса работают с одной локальной базой SQLite. Данные не отправляются в интернет.

## Логика расчёта

Каждая запись содержит дату, вид операции, собственника, на чей баланс она ложится, сумму, валюту, знак, направление («от кого» → «кому») и пояснение.

- **`+`** увеличивает задолженность выбранного собственника перед вторым;
- **`−`** уменьшает задолженность выбранного собственника;
- покупка, снятие денег или кредит Собственника 2 с `+` увеличивает долг Собственника 2 Собственнику 1;
- такая же операция Собственника 1 с `+` увеличивает долг Собственника 1 Собственнику 2;
- положительное итоговое сальдо означает «Собственник 2 должен Собственнику 1»;
- отрицательное — «Собственник 1 должен Собственнику 2».

Поддерживаются BYN и USD. Сумма в USD автоматически пересчитывается в белорусские рубли по официальному курсу **НБРБ** на дату операции (`api.nbrb.by`). Полученный курс сохраняется вместе с записью; при необходимости его можно указать вручную.

В программу включены: кредиты и иные поступления, покупки товаров, снятие наличных, проценты банка, штрафы, лизинг, инвестиционные расходы, возврат долга перечислением или наличными, личные покупки и ручная корректировка.

Операции **«Покупка товаров собственником — с вычетом налогов»** и **«Личная покупка собственника — с вычетом налогов»** автоматически рассчитывают взаимный долг за минусом входного НДС и экономии по налогу на прибыль. Введённая сумма считается ценой с НДС. При стандартных ставках 20% для суммы 100 BYN расчёт составляет: НДС 16,67 BYN, налог на прибыль 16,67 BYN, итоговый долг 66,66 BYN. Расчёт сохраняется в записи и показывается при наведении на строку. Ставки можно изменить в настройках текущей базы.

При встречном долге покупка сначала погашает его полной суммой, а налоговое уменьшение применяется только к превышению. Например: долг Собственника 2 — 100 BYN, покупка Собственника 1 — 150 BYN. Первые 100 BYN закрывают встречный долг; НДС и налог на прибыль рассчитываются с остатка 50 BYN; новый долг Собственника 1 равен 33,34 BYN.

В **«Настройках»** задаются два имени собственников и список фирм/контрагентов. По умолчанию используются «Собственник 1» и «Собственник 2». После сохранения участники доступны в выпадающих списках баланса, отправителя, получателя и источника депозита.

Операция **«Внесение на депозит»** добавляет деньги Собственника 1, Собственника 2 или сторонней организации, не меняя взаимный долг. В поле **«Источник депозита»** указывается, от кого получены деньги: например, `Собственник 2` или `ООО Ромашка`. Операция **«Расход из депозита / снятие»** уменьшает депозит с тем же именем источника. Все ненулевые остатки показываются над журналом строками «На депозите от …»; если источников несколько, отображается каждый.

## Запуск из исходного кода

Требуется Python 3.11 или новее.

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
python -m finance_balance
```

По умолчанию открывается GUI. Кнопка **«HTML-интерфейс»** запускает локальную страницу в браузере.

Только веб-интерфейс:

```bash
python -m finance_balance web --host 127.0.0.1 --port 8080
```

Затем открыть <http://127.0.0.1:8080>.

Дополнительные параметры:

```bash
python -m finance_balance gui --db D:\Finance\balance.db
python -m finance_balance web --db ./balance.db --port 9000
```

Без `--db` файл текущей базы (по умолчанию `fitnes.db`) хранится **рядом с программой** (`Fitnes.exe`). Там же находится `fitnes-config.json` с настройками и хешем пароля. При обновлении заменяйте только EXE и не удаляйте эти два файла. Для резервного копирования закройте программу и скопируйте `fitnes.db` вместе с `fitnes-config.json`.

## Погашение со счёта и наличными

Для операций возврата долга задаётся **путь возврата**:

- **со счёта** — долг уменьшается на всю введённую сумму;
- **наличными** — в баланс засчитывается половина введённой суммы.

Например, долг после налогового расчёта равен 66,66 BYN. Его закроет возврат 66,66 BYN со счёта либо 133,32 BYN наличными (`133,32 / 2 = 66,66`). Расчёт сохраняется во всплывающем примечании и экспортируется в CSV.

## Встроенная инструкция

В настольном окне нажмите **«Инструкция»**, а в HTML-интерфейсе — **«? Инструкция»**. Откроется подробное руководство с правилами знаков и готовыми примерами:

- кредит Собственника 2 и проценты по нему;
- возврат долга переводом;
- покупка Собственника 1 для себя;
- покупка Собственника 2 в USD с курсом НБРБ;
- внесение и расходование депозитов от нескольких источников;
- обновление программы без потери базы.

## Пароль и работа по сети

При первом запуске программа обязательно предлагает создать пароль длиной не менее 6 символов. Пароль запуска хранится в `fitnes-config.json` только в виде стойкого PBKDF2-хеша и проверяется:

- при каждом запуске настольного приложения;
- при входе в HTML-интерфейс по локальной сети.

В Fitnes используются **два независимых пароля**: пароль запуска приложения и отдельный пароль каждой базы. Пароль базы хранится внутри соответствующего SQLite-файла как PBKDF2-хеш. При переключении на другую базу программа запрашивает именно её пароль.

Кнопка **«Настройки»** позволяет изменить пароль запуска, изменить пароль текущей базы, добавить существующую базу или создать новую. Быстро переключаться между сохранёнными базами можно через список в верхней панели. Поддерживается путь к сетевой папке, например `\\SERVER\Share\fitnes.db`.

Для совместной работы предпочтительно включить **сетевой HTML-доступ**: приложение запустит защищённый паролем интерфейс на порту 8080 и покажет адрес вида `http://192.168.1.10:8080`. База при этом остаётся на одном компьютере. Прямое одновременное редактирование одного SQLite-файла несколькими программами на сетевом диске не рекомендуется.

> Пароль ограничивает доступ через программу, но не шифрует сам файл SQLite. Доступ к сетевой папке также следует ограничить средствами Windows/сервера.

## Встроенный калькулятор

Удерживайте **Ctrl** и нажимайте левой кнопкой по ячейкам столбца **«Исходная сумма»**. Первый Ctrl+клик добавляет сумму в расчёт и подсвечивает строку, повторный Ctrl+клик снимает выделение. Внизу появляется количество выбранных ячеек и общий итог в BYN. Суммы в USD автоматически учитываются в пересчёте по сохранённому курсу. При переключении базы выбор очищается.

Функция работает и в настольном, и в HTML-интерфейсе. В браузере появляется отдельная нижняя панель с кнопкой **«Сбросить»**.

## Редактирование и курсовая разница

Любую строку можно изменить без удаления: в GUI дважды щёлкните непосредственно по строке или выделите её и нажмите **«Редактировать выбранную»**; в HTML-интерфейсе нажмите значок карандаша. После каждого сохранения Fitnes автоматически создаёт неизменяемую отметку с локальной датой и временем. Отметка отображается в журнале, окне редактирования и CSV, а история предыдущих отметок сохраняется в базе.

Для валютного депозита при снятии выберите **«Расход из депозита / снятие»** и заполните исходную сумму в BYN, **курс внесения** и **курс получения**. Например, для 30 000 BYN при курсах 3,2 → 2,7 Fitnes рассчитает:

- валютный эквивалент: 9 375;
- фактически получено: 25 312,50 BYN;
- курсовая потеря: 4 687,50 BYN;
- списание депозита: 30 000 BYN;
- взаимная задолженность двух собственников: 0 BYN.

Курсовая разница отображается в сводке, журнале и CSV.

## Импорт CSV

В GUI и HTML-интерфейсе есть кнопка **«Импорт CSV»**. Импорт выполняется в текущую открытую базу и поддерживает UTF-8/Windows-1251, а также разделители `;`, `,` и табуляцию.

Обязательные столбцы: `Дата`, `Операция`, `Баланс`, `Знак`, `Сумма`. Необязательные: `Валюта`, `Курс внесения`, `Курс получения`, `От кого`, `Кому`, `Пояснение`. Экспортированный Fitnes CSV можно сразу импортировать обратно или использовать как шаблон. Перед записью проверяется весь файл; при любой ошибке импорт отменяется полностью. Повторная загрузка одного файла создаёт дубликаты.

## Возможности

- импорт и экспорт CSV;
- пароль при запуске и защищённый вход через браузер;
- открытие базы из локальной или сетевой папки;
- автоматический расчёт сальдо двух собственников;
- отдельные итоги прихода, расходов, начислений и погашений;
- единый журнал операций;
- удаление ошибочных записей с подтверждением;
- экспорт в CSV (UTF-8 с BOM, удобно открывать в Excel);
- адаптивный HTML-интерфейс для телефона и компьютера;
- локальная SQLite-база без отдельного сервера.

## Тесты и сборка

```bash
pip install -r requirements-dev.txt
pytest -v
```

GitHub Actions автоматически запускает тесты на Python 3.11/3.13, собирает Fitnes и создаёт полноценный установщик **Fitnes-Setup.exe** через Inno Setup. Результат публикуется в артефакте **Fitnes-Windows-Installer** workflow **Test and build**.

Установщик:

- устанавливает Fitnes в профиль текущего пользователя без запроса прав администратора;
- добавляет приложение в меню «Пуск»;
- по выбору создаёт ярлык на рабочем столе;
- регистрирует стандартное удаление программы;
- поддерживает обновление поверх установленной версии;
- не удаляет пользовательские базы и настройки при обновлении или обычном удалении.

При первом запуске можно выбрать файл базы от старой версии Fitnes. После выбора база автоматически обновляется до актуальной структуры без удаления операций.

## Предупреждение Chrome и Windows

Fitnes собирается открыто на GitHub Actions, но пока не подписан платным сертификатом Microsoft Authenticode. Поэтому Chrome или SmartScreen всё ещё могут показать «неизвестный издатель». Полностью убрать такое предупреждение без доверенного сертификата невозможно.

В артефакт включён `SHA256SUMS.txt`. Проверить скачанный установщик можно в PowerShell:

```powershell
(Get-FileHash .\Fitnes-Setup.exe -Algorithm SHA256).Hash.ToLower()
Get-Content .\SHA256SUMS.txt
```
