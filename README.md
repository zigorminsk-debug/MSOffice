# Сводный баланс Игоря и Юры

Локальная программа для учёта взаиморасчётов двух собственников. Есть два равноправных интерфейса:

- **GUI** — настольное окно для Windows/Linux;
- **HTML** — адаптивная страница, открывающаяся в браузере.

Оба интерфейса работают с одной локальной базой SQLite. Данные не отправляются в интернет.

## Логика расчёта

Каждая запись содержит дату, вид операции, сумму, знак, направление («от кого» → «кому») и пояснение.

- **`+`** увеличивает долг Юры перед Игорем;
- **`−`** уменьшает долг Юры перед Игорем;
- положительное итоговое сальдо означает «Юра должен Игорю»;
- отрицательное — «Игорь должен Юре».

В программу включены: кредиты и иные поступления, проценты банка, штрафы, лизинг, инвестиционные расходы, возврат долга перечислением или наличными, личные покупки Игоря и ручная корректировка. Для каждого типа предлагается знак по умолчанию, но его можно изменить.

Пример: кредит, который забрал Юра, вносится со знаком `+`. Проценты и штрафы по нему также вносятся с `+`. Деньги, возвращённые Юрой Игорю, и монитор, купленный Игорем себе в зачёт долга, вносятся с `−`.

## Запуск из исходного кода

Требуется Python 3.11 или новее.

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
python -m finance_balance
```

По умолчанию открывается GUI. Кнопка **«HTML-интерфейс»** запускает локальную страницу в браузере.

Только веб-интерфейс:

```bash
python -m finance_balance web --host 127.0.0.1 --port 8080
```

Затем открыть <http://127.0.0.1:8080>.

Дополнительные параметры:

```bash
python -m finance_balance gui --db D:\Finance\balance.db
python -m finance_balance web --db ./balance.db --port 9000
```

Без `--db` база хранится в `~/.igor_yura_balance/balance.db`.

## Возможности

- автоматический расчёт сальдо Игоря и Юры;
- отдельные итоги прихода, расходов, начислений и погашений;
- единый журнал операций;
- удаление ошибочных записей с подтверждением;
- экспорт в CSV (UTF-8 с BOM, удобно открывать в Excel);
- адаптивный HTML-интерфейс для телефона и компьютера;
- локальная SQLite-база без отдельного сервера.

## Тесты и сборка

```bash
pip install -r requirements-dev.txt
pytest -v
```

GitHub Actions автоматически запускает тесты на Python 3.11/3.13 и собирает автономный Windows-файл `Balance-Igor-Yura.exe`. Готовый файл находится в артефакте **Balance-Igor-Yura-Windows** соответствующего запуска workflow **Test and build**.
